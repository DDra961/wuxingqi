# 测试脚本

## 目录

- `run_tests.mjs`：构建并运行全部游戏/编辑器回归用例
- `cases/`：机制、敌人模板、关卡接入、布阵、关卡编辑器用例
- `lib/`：DOM/Canvas 测试桩与游戏模块构建器
- `balance/`：数值模拟回归（阵容 × 关卡 × BOSS）
- `tools/`：关卡批量生成 / 检查脚本
- `output/`：数值模拟输出（CSV + Markdown）
- `.build/`：运行时生成的测试模块，可随时删除

## 运行

```powershell
node 测试脚本/run_tests.mjs
node 测试脚本/balance/run_balance.mjs
node 测试脚本/balance/growth_sim.mjs
node 测试脚本/balance/run_campaign.mjs
```

数值模拟默认使用难度 5、5 种主角属性、6 种队友组合、35 个关卡、2 个随机种子。  
它模拟的是不带藏品、求签、结算和关卡外成长的基础队伍，使用固定贪心策略，因此用于找异常关卡和相对强弱，不等同于真实通关率。  
测试站位为：二环自己属性节点优先，被占用时逐环外扩、同环按 ID 尝试。  
结果分析和争议项见项目根目录 `测试结果整理.md`。

## 关卡工具

`tools/` 下的生成/检查脚本沿用当前项目路径。运行前确认 `关卡集/` 已存在；生成脚本会拒绝覆盖已有文件，检查脚本只读。
