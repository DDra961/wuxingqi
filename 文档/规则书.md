# 五行棋盘 · 规则书

> 前面 1 分钟看懂怎么玩，后面约 5 分钟读完完整规则。
> 适用当前计划 8 版本。

## 一分钟上手

1. **开局**：选难度 → 选主角主属性 → 四把宝剑三选一 → 四名队友选二（主角固定）。
2. **布阵**：依次点击高亮格，把三名角色放到棋盘上，然后确认开战。
3. **每回合**：为我方每名存活角色选一个技能；需要目标时再点目标，最后点「确定决策」。
4. **结算**：系统按固定顺序自动结算。30 回合内全灭敌人即胜利，我方全灭或超时判负。
5. **走路线**：共 7 层，第 1 层打怪，第 7 层 BOSS；中间可打怪、奇遇或休息。
6. **记住三件事**：五行与格子属性都能克制；防御能减伤并击退；每场战斗资源回满，永久成长保留。

## 一、棋盘与五行

- 棋盘为 **51 格**五边形：中心 1 格，外圈依次 5 / 10 / 15 / 20 格。
- 中心格**无属性**；其余格子按五个区域分属金、木、水、火、土。
- 五行相克：**金克木 → 木克土 → 土克水 → 水克火 → 火克金**。
- 克制分为两部分，各自独立计算。
- 单项克制值随层数成长，但不受难度影响：第 1~3 层 `±1`，第 4~6 层 `±2`，第 7 层 `±3`。
- 角色主属性克制或格子属性克制时取正值，被克时取负值。
- 两项合计后，中心格不参与格子属性判断。
- 普通攻击伤害 = `攻击力 + 克制值`；目标防御时再减去其防御力。
- 本命一击：只要**角色属性**或**格子属性**满足任意一种克制，就造成 `攻击力 × 3` 伤害。

- **队友**：基础技能 + 各自两个专属技能。

## 三、回合流程

每回合分为三个阶段：

1. **状态结算**：清空本回合受伤累计；无力状态角色跳过本回合，并减少状态回合数。
2. **决策**：敌人自动决策；玩家依次为每名存活角色选技能和目标。
3. **结算**：按角色编号固定顺序行动（主角 → 队友 → 敌人），每次行动后刷新界面和日志。

补充：

- 决策是同时提交的。你看到的“目标防御/闪避”是目标本回合的选择。
- 已倒下的角色不参与后续结算。
- 30 回合内未分出胜负，主角阵营判负。
- 同一格可以站多人，模型会按进入顺序堆叠并缩小。

## 四、行动与伤害结算

### 基础行动

| 行动     | 消耗 | 效果                                               |
| -------- | ---- | -------------------------------------------------- |
| 普通攻击 | 1 魔 | 攻击距离内单体，造成攻击力 + 克制伤害              |
| 普通防御 | 无   | 被动防御：被攻击时按防御减伤、防御 -1、被击退 1 格 |
| 普通闪避 | 1 体 | 移动到 2 格内落点；被攻击时每次闪避再耗 1 体       |
| 普通法术 | 1 魔 | 把一格改成自己的主属性                             |
| 普通回元 | 无   | 回复 2 点魔力                                      |
| 普通休息 | 无   | 回复 1 点体力                                      |
| 普通移动 | 无   | 向相邻格移动 1 步                                  |
| 法术治疗 | 1 魔 | 一名队友（含自己）回复 1 点体力                    |

### 结算细节

- 防御成功时：先减去防御力，再使防御力 -1，并把目标击退一格；BOSS 不被击退。
- 闪避需要体力；体力不足时无法闪掉该次攻击。
- 技能消耗在行动结算时扣除。目标已倒下或超出距离时行动落空，消耗照扣。
- 血量降到 0 或以下立即倒下。
- “无力”状态会让角色下一回合无法决策。

## 六、敌人与 BOSS

### 普通敌人模板

| 模板 | 名称   | 特点                                                   |
| ---- | ------ | ------------------------------------------------------ |
| 1    | 无特殊 | 山洞中的魔物；使用基础行动                             |
| 2    | 腐蚀   | 攻击富含剧毒的蛇怪，技能会削减防御                     |
| 3    | 嘲讽   | 由天然石头变化而成的妖，在攻击范围内时不能攻击其它敌人 |
| 4    | 变换   | 由怨气聚合的虚影，技能会改变地形                       |

- 普通敌人只使用基础技能，不会使用主角的扩展技能。
- 敌人基础值来自关卡文件，再按难度和层数成长；攻击距离不参与成长。

### BOSS

- BOSS 占据四格菱形，四个部位共享一条血量；每回合只行动一次。
- 每个部位整场第一次受击后会被标记；回合末每个已标记部位使 BOSS 损失 `ceil(最大生命 / 8)`。
- 同一部位重复攻击不会再次触发部位伤害。
- 生命首次低于一半时狂暴，攻击力提升 50%。
- 默认数值：60 生命 / 6 攻击 / 6 防御 / 0 体力 / 12 魔力 / 距离 3；只按难度缩放。

| BOSS 技能 | 消耗 | 效果                                     |
| --------- | ---- | ---------------------------------------- |
| 鞭挞      | 2 魔 | 攻击范围内至多两名角色                   |
| 穿刺      | 2 魔 | 单体高伤，无视防御                       |
| 反击      | 无   | 防御时反伤 1 点并回复 1 魔               |
| 压制      | 2 魔 | 1 点固定伤害并施加「无力」1 回合         |
| 爆发      | 2 魔 | 全图格子变为 BOSS 主属性                 |
| 抽取      | 无   | 每名存活角色失去 1 魔，BOSS 回复抽取总量 |

## 七、肉鸽路线与成长

- 共 **7 层**：第 1 层固定打怪，第 7 层固定 BOSS，第 2~6 层为打怪 / 奇遇 / 休息。
- 每层通常有 2~3 个可选节点；同层同类型节点合并显示，地图仍会画出具体后继连线。
- 难度 1~10；幸运值 = `65 - 5 × 难度`。幸运影响节点类型概率、求签权重和幸运结算概率。
- 休息：全队生命上限 **+1**（永久）。
- 奇遇：四件宝物中随机三选一，每层最多获得一件藏品。
- 战斗结算三选一：
  1. 全队生命上限 +1；
  2. 随机一名角色攻击力 +2；
  3. 获得一件随机宝物。
- 有 `幸运 / 2 %` 概率触发幸运结算，随机强化一项：生命上限 +2、单体攻击 +4，或宝物两件。

### 藏品

- 藏品上限 10 件；每层最多获得一件，战斗结算的随机宝物例外。
- 战斗中可用的单次藏品不占行动，每回合限一次。
- 战斗内增益在战后按战前快照恢复；永久攻击、防御、生命上限等保留。

## 八、界面与存档

- **顶栏**：回合数、阶段、行动顺序、重新开始、关闭服务。
- **右侧**：路线地图、技能面板、战斗日志。
- **底栏**：三名我方角色与敌人的角色卡，显示生命、攻击、防御、体力、魔力、距离、行动和角色介绍。
- **角色档案**：点击底栏任意角色卡，可在棋盘左侧查看立绘、基础属性和介绍。
- **左上方**：藏品卡，可折叠查看持有藏品。
- 存档 key 为 `wuxing_run_v1`，当前版本 v4；旧 v1~v3 存档继续兼容。
- 战斗不存档；刷新后从本层选择重来。胜利、失败或回到启动页会清除存档。

## 九、上手建议

1. 先用普通攻击和普通防御熟悉“属性克制 + 格子克制”。
2. 需要爆发时再打本命一击；没有克制时它不会造成伤害。
3. 防御不是白挨打：能减伤、削防、击退，部分技能还能反击。
4. 闪避很耗体力，优先用来躲高伤技能，不要每回合都闪。
5. 路线选择优先补生命上限和主力攻击力，再考虑藏品组合。
