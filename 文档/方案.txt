一、目标
--------------------------------------------------------------------
浏览器内运行的 3D 战棋小游戏。五边形棋盘上共 51 个圆形格子，
主角团五人角色池，采用「五选三」：主角固定，四名队友中选两名，
与关卡敌人对战，五行相克，
每回合每人选择「攻击 / 防御 / 闪避 / 法术 / 回元」之一后统一结算。

MVP 只验证三件事：
  1. 五边形 + 五层环格（51 格）的棋盘读得懂
  2. 五行克制在棋盘上的体现有策略感
  3. 技能与回合制的完整闭环能玩（计划1 五技能 → 计划2 扩到 16 个）

二、技术方案
--------------------------------------------------------------------
2.1 运行形态
    - 单文件 index.html + Three.js（本地 app/three.module.js，importmap 引入）
    - 双击打开会因 ES 模块跨域限制失败，必须走本地静态服务
    - 最简方式：双击目录下的「启动游戏.bat」
      （端口已占用则直接开浏览器，不重复起服务）
    - 启动脚本会等端口真正监听后再开浏览器（最多 20 秒）；
      起不来就把 logs/server.log 打出来，并提示检查 Python / 防火墙 / 端口占用
    - 手动方式：python app/server.py 8765
                浏览器访问 http://127.0.0.1:8765/index.html
    - 关卡编辑器：策划工具，双击「app/启动关卡编辑器.bat」打开；
      地址为 /app/level_editor.html，与游戏共用 8765 服务（编辑器自己发心跳）；
      游戏内不再提供入口
    - 关卡文件统一保存到项目根目录的「关卡集」文件夹
    - 关闭页面即安全退出：
        页面每 2 秒发一次心跳；关闭标签页时发一次告别信标，
        服务器 4 秒内自行退出；浏览器崩溃则心跳超时 15 秒后退出。
        页面右上角另有「关闭服务」按钮，点击后服务器 1 秒内立即退出
        （页面本身仍可继续玩，只是刷新需要重新双击 bat）。
        多个标签页同时开着时，只要还有一个在心跳，服务就不会退出。
        注意：标签页被浏览器挂起超过 5 分钟后心跳会停，服务可能提前
        退出；此时游戏页面仍能继续玩，只是刷新需要重新双击 bat。

三、棋盘几何（★ 按你的确认定稿）
--------------------------------------------------------------------
3.1 构成
    - 正五边形，边长 5 单位，外接圆半径 R = 5 / (2·sin36°) ≈ 4.2533
    - 五个顶点各连一条线到中心，共 5 条辐条
    - 同一环上的点互相连接，形成 4 个互相嵌套的五边形
    - 5 条辐条把棋盘分成 5 个区域（三角扇形）

3.2 格子数量（★ 已确认为 51 格，格点即格子，用圆形表现）
    环号      格子数      每区域      说明
    --------------------------------------------------
    第 1 环      1         —         中心，无属性
    第 2 环      5         1         最内圈五边形顶点
    第 3 环     10         2
    第 4 环     15         3
    第 5 环     20         4         最外圈，即五边形边上的点
    --------------------------------------------------
    合计        51

3.3 生成方式（实现用）
    第 r 环（r=2..5）是把外五边形按 (r-1)/4 缩放后、每条边等分成 (r-1) 段
    得到的点，因此每条边上有 (r-1) 个点，全环 5(r-1) 个点。
    环内相邻点间距恒为 1.25，环间径向间距约 1.063，是一张规整的极坐标网格。

3.4 坐标与区域归属
    坐标写作 (区域, 环, 序号)，其中序号按「逆时针」计数。
    - 区域 0..4，从前一个顶点转到下一个顶点为一个区域
    - 归属规则：每个区域包含顺时针方向的边、不包含逆时针方向的边
      → 每个区域在任意环上恰好拿到 (环号 - 1) 个点
    坐标示例：
        中心           → ( — , 1, 1)
        金区域最内点   → ( 0 , 2, 1)
        木区域最外第 3 点 → ( 2 , 5, 2)

3.5 邻接
    以几何距离判定，阈值 1.35（环内 1.25 / 环间 1.06 相连，次近 1.7 不相连）
    结果：内部格 6 邻居，外圈格 3~4 邻居，中心 5 邻居。
    同时预计算全图步距（BFS）：攻击距离、闪避落点都用「步数」判定，
    与「移动一格」的语义保持一致。

3.6 颜色与属性（区域按五行相生的顺时针顺序排列）
    区域 0 = 金（黄）→ 区域 1 = 水（蓝）→ 区域 2 = 木（绿）
    → 区域 3 = 火（红）→ 区域 4 = 土（棕）
    格子主属性 = 所属区域属性（1.0 版），中心格无属性。

3.7 透视
    镜头为半俯视，棋盘在画面中呈透视梯形效果；
    棋盘本身仍在 XZ 平面上按真实正五边形建模。

    角色     阵营    主属性     可用技能
    ----------------------------------------------------
    主角     我方    开局自选   0~16（全部）

五、五行克制
--------------------------------------------------------------------
相克链：金克木 → 木克土 → 土克水 → 水克火 → 火克金

【克制】返回值 = 人物属性克制 / 被克 / 无关
                + 格子属性克制 / 被克 / 无关
    - 单项克制值只吃层数加成，不吃难度加成：
        第 1~3 层 ±1；第 4~6 层 ±2；第 7 层 ±3
    - 两项合计范围随层数扩大；中心格不参与格子属性那一项。

六、技能表
--------------------------------------------------------------------
技能由表驱动。一条记录包含：编号 / 技能名 / 决策类别 / 消耗 /
目标类型 / 参数 / 结算方法。决策只记录技能编号与目标，结算时按编号
查表执行。编号 0~5 与 16 是基础技能，6~15 是计划2 新增（仅主角拥有）。

编号  技能名     类别  消耗   目标             效果
--------------------------------------------------------------------
0     普通攻击   攻击  1魔    攻击距离内敌人   伤害 = 攻击力 + 克制值
1     普通防御   防御  —      自身             被动：减伤、防御-1、被击退
2     普通闪避   闪避  1体    2 格内落点       移动 2 格（耗 1 体），被攻击每闪避一次再耗 1 体
3     普通法术   法术  1魔    任意格           该格属性变为自己主属性
4     普通回元   回元  —      自身             魔力 +2
5     普通休息   休息  —      自身             体力 +1
6     破锋      攻击  2魔    攻击距离内敌人   伤害 = 攻击力 + 克制值 + 目标格变为自己属性
7     裂阵      攻击  4魔    攻击距离内敌人   伤害 = 攻击力 + 克制值 + 目标周围格变为自己属性
8     反戈      防御  —      自身             防御后反击伤害来源 1 点
9     敛锋      防御  1魔    自身             防御后消耗 1 魔恢复 1 防御力
10    踏云      闪避  2体    3 格内落点       移动 3 格（耗 2 体），被攻击每闪避一次再耗 1 体
11    无痕      闪避  3魔    2 格内落点       移动 2 格，本轮闪避不再耗体力
12    淬锋      法术  2魔    自身             攻击力 +1
13    失神      法术  3魔    任意敌人         目标进入「无力」1 回合
14    引灵      回元  —      另一名队友       自身与目标各 +1 魔力
15    调息      休息  —      自身             体力 +1；结算前未受伤再 +1
16    普通移动   移动  —      相邻格           移动 1 步，不消耗资源

通用约定：
- 攻击类均吃五行克制加成；目标选择防御时按「伤害 - 防御力」减免
- 闪避类技能「移动」即消耗体力（普通闪避 1 点、踏云 2 点、无痕 不耗体）；
  只有成功闪掉一次攻击才扣 reactionCost 点体力（普通闪避 / 踏云 各 1 点，
  无痕 为 0），体力不足则该次闪避不成立
- 攻击类技能均以攻击力为伤害基础：破锋 / 裂阵 = 攻击力 + 克制；
  淬锋 的攻击力加成影响所有攻击
- 反戈 的反击固定 1 点，不吃克制、不减免、不击退
- 裂阵 转换的是目标格「周围」的相邻格，不含目标格本身
- 引灵 的目标是另一名队友（自身始终已包含），无存活队友时不可用

--------------------------------------------------------------------
七、战斗状态
--------------------------------------------------------------------
每个角色持有一个战斗状态对象：{ 状态key, 剩余回合 }。
状态定义放在注册表里（STATUS_DEFS），后续新增状态只需加一条：

    normal 正常   —— 无影响
    weak   无力   —— 本回合无法决策

流程：
    1. 每回合进入决策前先做状态结算
    2. 无力状态的角色本回合跳过决策，计时器 -1
    3. 计时器归零后回到正常，并写一条日志
    4. 一个角色同时只能处于一种状态（新状态直接覆盖旧状态）

★ 先判定「能否决策」再扣计时器，保证 1 回合的无力正好少行动一次。
★ 回合中途被施加的无力，从下一回合的决策阶段开始生效。

--------------------------------------------------------------------
八、回合流程
--------------------------------------------------------------------
每个回合分三阶段：

阶段一：状态结算
    1. 清空本回合受伤累计
    2. 逐个角色判定状态；无力者标记跳过并扣计时器

阶段二：决策
    1. NPC 在回合开始时按决策规则产生行动
    2. 玩家依次为我方每个存活角色选择技能（需目标的技能再选目标）
    3. 全部决策存进【回合控制】数组

阶段三：结算
    1. 按固定角色顺序（主角→队友1→队友2→敌人1→敌人2）逐个结算
    2. 防御直接跳过（被动）；攻击读取目标本回合的决策
    3. 已倒下的角色不参与结算
    4. 每步行动后刷新界面并写日志
    5. 回合结束判定胜负；未结束则回合数 +1

★ 结算顺序固定为角色编号顺序，不轮转。

--------------------------------------------------------------------
九、边界、死亡与胜负
--------------------------------------------------------------------
- 击退时若已无法离攻击者更远 → 原地不动
- 同一格子可以站多个角色（渲染时按到达先后纵向堆叠，每层 +0.62）
- 攻击只能选攻击距离（默认 4 步）内的目标；提交与结算各校验一次
- 闪避落点必须是 1~N 步内（普通闪避 / 无痕 为 2 步，踏云 为 3 步）
- 技能消耗在行动结算时扣除；目标已倒下或超距则行动落空，消耗照扣
- 血量 ≤ 0 立即离场，不再行动（★ 原文写「小于 0」，实现取 ≤ 0 更自然，
  如需严格按原文可改）
- 回合结束时：一方全灭 → 另一方胜；双方同时全灭 → 平局
- 30 回合内未分出胜负 → 主角阵营判负（右上角顶部显示 第 X / 30 回合）

--------------------------------------------------------------------
十、NPC 决策
--------------------------------------------------------------------
    有魔力且攻击距离内有敌人 → 普通攻击血量最低的目标
    有魔力但攻击距离内没有敌人 → 普通移动，朝最近的敌人走一步
    否则有体力 → 普通闪避（随机 2 格内落点）
    否则 → 普通防御
    NPC 只用基础技能 0~5 与 16，不会使用主角的扩展技能。

技能说明卡
    - 位置：棋盘区域右上角，半透明浮层，不挡操作
    - 内容：类别标签 / 角色·技能名 / 消耗 / 效果说明
    - 触发：悬停技能按钮时预览；点选技能后保持显示，直到换目标或换回合

决策确认
    - 点技能不会立即确认，只是进入「已选」状态
    - 需要目标的技能还要再点棋盘选目标，目标选完【确定决策】才可用
    - 【确定决策】固定在技能列表下方，可用时高亮，不可用时置灰
    - 技能列表高度固定、内容可滚动，方便后续继续加技能
    - Esc 或重选技能可放弃当前选择

藏品卡与弹窗
    - 藏品卡固定在棋盘左上角，可折叠，显示持有藏品的名称、类别、效果
      与单次数量；战斗中生效的会标注「本场已生效」
    - 求签：开战时弹出，点击棋盘任意处关闭
    - 奇遇（宝物三选一）/ 休息 / 战斗结算 / 胜负：棋盘中央弹窗

交互
    - 攻击 / 失神：点技能 → 有效目标高亮 → 点击目标
    - 闪避 / 移动：点技能 → 落点范围内格子高亮 → 点击落点
    - 引灵：点技能 → 存活队友高亮 → 点击队友
    - 无目标或资源不足的技能直接置灰
    - 右上角「关闭服务」立即关停本地服务，页面仍可继续玩

    1     —      —                        被动：减伤后防御 -1 并被击退

    3     1魔    —                        1 格属性改写
    4     —      魔力 +2                  —

    12    1魔    —                        攻击力 +1
    13    3魔    —                        目标无力 1 回合
    14    —      双方魔力 +1              —
    15    —      体力 +1，无伤再 +1        —
    16    —      —                        移动 1 步

伤害公式
    普通攻击 / 攻击类技能：max(攻击力 + 克制值, 0)
    目标防御：max(上式 - 防御力, 0)，随后防御力 -1，再被击退一格
    目标闪避：扣反应体力后攻击无效，且不结算攻击附带的格子改写 /
                变换 / 削甲等效果；体力不足则按未防御结算
    攻击落空：距离不足、目标失效或被闪避时，技能消耗已扣，不结算伤害与附带效果

十四、肉鸽路线（计划3 第一步）
--------------------------------------------------------------------
14.1 启动页
    - 全屏开屏页：标题 + 难度上下调整（1~10）+ 开始游戏
    - 幸运值 = 65 - 5 × 难度（难度 1 → 60，难度 10 → 15）
    - 开场页只显示「敌人属性：×当前倍率」，具体成长规则见 16.5 / 后续规则书
    - 点开始游戏 → 生成整条路线 → 进入第 1 层选择

14.2 关卡结构
    - 共 7 层，第 1 层固定「打怪」，第 7 层固定「BOSS」
    - 第 2~6 层的节点类型：打怪 / 奇遇 / 休息
    - 每层的可选项 = 上一节点按规则生成的子节点（选择会影响后续）
    - 同层同类型节点合并，保证每层只有 2~3 个节点，地图可读
    - 所有第 6 层节点都只连到唯一的 BOSS

14.3 生成规则（p 为受幸运影响的概率）
    p = clamp(0.5 + (幸运 - 40) × 0.005, 0.2, 0.85)
    打怪 → 打怪 + 休息 +（p×0.5 概率）奇遇       → 2~3 个
    奇遇 → 打怪 + 休息                           → 2 个
    休息 → 打怪 +（p 概率）奇遇                  → 1~2 个
    - 幸运还影响求签权重与结算强化概率，见 16.3 / 16.4
    - 幸运不影响战斗数值、敌人 / 关卡 / BOSS 抽取、宝剑候选、
      奇遇/结算宝物的具体内容与角色成长

14.4 流程
    1. 每层弹出选择窗口：显示「第 X / 7 层」「已通过 N / 7 层」与本层可选行动
    2. 选打怪 / BOSS → 进入棋盘战斗
       胜利 → 结算窗口「战斗胜利」+【下一步】
       失败 → 弹窗「你输了」+【回到启动页面】（重置肉鸽对象）
    3. 选奇遇 / 休息 → 提示文本 +【下一步】（效果 TODO）
    4. 第 7 层结束 → 「你胜利了」+【回到启动页面】
    - 地图固定在右侧，改为可上下左右滚动的画布：7 层纵向排列，
      层号固定在窗口左侧；当前节点自动滚到可视区中间偏上，
      待选择节点位于中间偏下，走过的路径高亮
    - 每层节点按数量居中：1 个在 0.5，2 个在 0.33/0.67，
      3 个在 0.25/0.5/0.75；窗口左右范围视为 0~1
    - 上一层的每个节点与其具体后继节点之间画连线，合并后的同类节点
      也会显示所有来源连接，玩家可以滚动画布查看其它路线
    - 步骤选择弹窗底部不再显示横向路线图，画布只在右侧地图面板中展示
    - 每场战斗开始时重置场地与角色：格子属性回到初始区域属性（中心无属性），
      角色回到满状态、站回各自顶点

14.5 后续（已随计划3 补齐）
    - 怪物数值：已按难度与层数公式实现，见 16.5
    - 奇遇 / 休息：已实现，见 16.1 / 16.2
    - 战斗状态继承：已实现，开战只回出发点
    - 仍待做：背包丢弃 / 替换、各类藏品扩充

十五、宝剑 / 队友 / 藏品（计划3 第二步）
--------------------------------------------------------------------
15.1 藏品类
    - 宝剑与藏品同属藏品类，统一记在 run.artifacts（{ id, count }）
    - 效果分三类：
        战斗外 out  ：打开本层选择窗口之前触发（决定行动前）
        战斗内 in   ：分两种时机
                       开场型   —— 战斗开始、第 1 回合决策前结算（数值类）
                       行动后型 —— 每个单位行动后触发（反应类，预留给后续藏品）
        单次 once   ：我方任一角色决策时手动使用，不占行动、每回合限一次，
                      且先于所有角色行动结算
    - 藏品卡固定在棋盘左上角，可折叠，随时查看持有藏品
    - 决策选项下方列出所有单次类藏品与数量；非我方角色决策时置灰
    - 藏品上限 10 件（背包上限与丢弃留 TODO）

15.2 测试用四把宝剑
    名称  类别    效果
    ------------------------------------------------------------
    龙泉  战斗外        幸运值 +10（永久）
    太阿  单次          主角团回复全部血量（数量 1，使用后消失）
    干将  获得时        主角团攻击力 +2（永久）
    莫邪  获得时        主角团体力 / 魔力上限 +2（永久）

15.3 主角团队（计划5 第六步）
    - 主角主属性由开局选择决定（五角星五选一），不再固定为金
    - 四名队友：沈桐桐（金）、芊儿（木）、念乔（水）、赤遥（火）
    - 队伍为「五选三」：主角固定，四名队友中选择两名上阵
    - 五名角色都拥有独立数值与两个特殊技能，选谁就用谁的技能
    - 全员共享「法术治疗」：1 魔，选择一名队友（含自己）回复 1 点体力
    - 主角固定拥有「本命一击」：3 魔，属性克制或格子克制满足任意一种时
      造成攻击力×3 伤害，否则不造成伤害
    - 主角按主属性解锁一个五行法术：
        金 炼兵 / 木 修养 / 水 涌动 / 火 爆炎 / 土 起甲
    - 队友特殊技能：
        沈桐桐  御金（嘲讽 + 首击护甲 +1）、铸甲（全队本场防御 +1）
        芊儿    生机（攻击力/2 伤害并治疗主角）、自然（改队友格属性并治疗）
        念乔    淡修（攻击伤害并削魔力）、潮息（队友本场攻击 +2）
        赤遥    灼焰（攻击伤害并额外削防）、爆轰（消耗全部魔力造成伤害）
    - 主角五行法术每次使用后提高下一次的魔耗；起甲每场限一次

15.4 开局流程
    启动页（选难度）→ 选主角主属性（五角星）→ 宝剑三选一（选中 + 确定）
    → 五选三（主角固定，四名队友选二）→ 生成路线 → 第 1 层选择
    - 队友按点击顺序作为队友1、队友2；未选中的两人本局不参战

15.5 存档与配置
    - 每进入一层选择时把进度写入 localStorage：难度、路线、已走节点、藏品、
      主角主属性、随机种子、三人队伍状态（最大生命 / 攻击 / 防御 / 上限）
    - 存档 v4；旧 v1~v3 存档继续可用，按角色 id 迁移到三人队伍，
      v1 恢复时补上干将 / 莫邪的永久加成
    - 启动页检测到存档时显示「继续上次」，恢复后回到当前层的选择窗口
    - 战斗不存档（刷新后从本层选择重来）；胜利 / 失败 / 回到启动页时清除存档
    - 关键数值集中在 CONFIG：回合上限、层数、幸运公式、主角基础属性、藏品数值
    - 藏品生效时顶部弹出提示，藏品卡在战斗中标注「本场已生效」

十六、关卡事件与数值（计划3 第三步）
--------------------------------------------------------------------
16.1 奇遇
    - 从四件宝物中随机抽三件，三选一获得（每层最多获得一件藏品）
    名称    类别    效果
    ------------------------------------------------------------
    回春丹  单次    全队立刻回复 2 点生命
    聚灵珠  获得时  主角魔力上限 +3（永久）
    强身符  获得时  全队体力上限 +2（永久）
    刺心钉  单次    对一名敌人造成 3 点固定伤害

16.2 休息
    - 全队生命上限 +1（永久）

16.3 求签（每场战斗开始时）
    - 幸运影响签的权重；设 d = (幸运 - 35) / 5：
        大吉 = 10 + d
        中吉 = 20 + 2d
        小吉 = 40 + 4d
        小凶 = 20 - 2d
        大凶 = 10 - d
    - 抽签时按五项权重总和归一化，权重总和不一定等于 100
    - 抽到后在战斗开始时弹窗提示，点击任意处关闭，同时把签名与效果写进战斗日志
    大吉：全体攻击力 +1（本场）
    中吉：主角攻击力 +1（本场）
    小吉：获得一件宝物【回春丹】
    小凶：主角本场攻击 -1
    大凶：全队本场攻击 -1

16.4 战斗结算
    - 战斗胜利后三选一，选完点【下一步】继续
    1. 全队生命上限 +1（永久）
    2. 随机一名角色攻击力 +2（永久）
    3. 必得一件随机宝物，不受本层已获得限制
    - 有 (幸运 / 2)% 概率触发幸运结算：随机一个结算项获得强化
        生命上限 +1 → +2
        随机单体攻击力 +2 → +4
        随机宝物一件 → 两件
    - 被强化的结算项在弹窗中高亮，并标注「（幸运）」

16.5 数值与成长
    主角团初始（血量 / 攻击 / 防御 / 魔力 / 体力 / 攻击距离）：
        主角    12 / 3 / 3 / 4 / 4 / 3
        沈桐桐  15 / 3 / 4 / 4 / 4 / 3
        芊儿    10 / 3 / 2 / 5 / 3 / 4
        念乔    12 / 3 / 3 / 4 / 3 / 3
        赤遥    10 / 4 / 3 / 6 / 3 / 4
    角色介绍（战斗角色卡与档案卡显示）：
        主角：被背叛的修仙者，从凡尘中崛起的大能
        芊儿：来自云芝山的木系仙女，寻求真正的心
        沈桐桐：砺剑门的圣女，万人敬仰
        赤遥：焚天宗宗主，实力在乾南数一数二
        念乔：虽为散修，但与主角同行，实力渐长
        无特殊：山洞中的魔物
        嘲讽：由天然石头变化而成的妖，在攻击范围内时不能攻击其它敌人
        腐蚀：攻击富含剧毒的蛇怪，技能会削减防御
        变换：由怨气聚合的虚影，技能会改变地形
        BOSS：山洞深处的双头食人花，四个根须是他的弱点，小心他非常强大
    敌人关卡基础值示例：普通 7 / 1 / 2 / 2 / 2 / 2；BOSS 60 / 6 / 6 / 0 / 12 / 3
    - 普通敌人（第 1~6 层）：
        基础值 = floor(关卡基础值 × (0.6 + (难度 - 1) × 0.1))   ← 难度影响
        战斗值 = floor(基础值 × (1 + (层数 - 1) × 0.1))        ← 层数影响
    - 第 7 层 BOSS：只乘难度系数，不乘层数
        难度 1 为 ×0.6，难度 5 为 ×1.0，难度 10 为 ×1.5
    - 攻击距离不参与难度 / 层数成长，取关卡文件中的值
    - 属性克制 / 格子克制单项值：1 + floor((层数 - 1) / 3)，
      即第 1~3 层 ±1、第 4~6 层 ±2、第 7 层 ±3；不吃难度加成
    - 玩家资源每场刷新：HP / 体力 / 魔力回满；永久攻击 / 防御 / 上限 /
      最大生命保留
    - 战斗内增益（求签、淬锋 等）在战前快照之后生效，战斗结束按快照恢复
    - 干将 / 莫邪改为永久加成，不参与本场回退

16.6 藏品限制
    - 每层最多获得一件藏品（不管走哪个节点）；战斗结算的随机宝物例外，
      不受本层已获得限制

16.7 重开与随机一致性
    - 进入战斗时保存「战前快照」：玩家血量/体力/魔力/永久加成、藏品、

    - 求签沿用本层结果（按「种子 + 层号」生成，不重摇）

16.8 开战布阵（计划4 第一步）

    - 布阵只属于本场战斗，重开 / 刷新会重新布阵；求签结果不变

    - 棋盘：中间为 2D SVG 五边形棋盘，51 格初始全部无属性；

    - 敌人列表（右侧）：
         + 新增敌人：模板默认 1，主属性默认金，血量 / 攻击力 / 防御力 /

         + 新增 BOSS：模板 5，四格菱形占位，默认血量 60 / 攻击 6 / 防御 6 /

16.11 BOSS 模板（计划5 第一步）
    - 索引 5，占据四个相连格组成菱形；编辑器默认菱形 1/2/3/41，
      可拖动到其它空出的四格菱形；游戏侧按关卡 cells 放置（接入待做）
    - 单体 BOSS 共享血量：四个部位只是受击区，BOSS 每回合只行动一次
    - 部位首次受击：每个部位在整场战斗中第一次被攻击时标记；
      每回合结算完 BOSS 行动后，每个已标记部位使 BOSS 失去
      ceil(最大血量 / 8) 点血量；同一部位重复攻击不再次触发
    - 狂暴：部位结算后，若生命首次低于最大血量一半，基础攻击力 +50%
      （向上取整），之后的鞭挞 / 穿刺等攻击都使用提升后的攻击力
    - 特殊行动：
        鞭挞  2魔  选至多两名攻击范围内的存活玩家，各造成 攻击力 + 克制 伤害
        穿刺  2魔  选一名攻击范围内的玩家，造成 攻击力 + 克制 伤害，无视防御
        反击  0魔  防御姿态；每次被攻击时正常按防御减伤、防御 -1、不被击退，
                   并反伤攻击者 1 点、回复自身 1 魔
        压制  2魔  选一名玩家，造成 1 点固定伤害并附加「无力」1 回合
        爆发  2魔  全地图格子属性变为 BOSS 主属性
        抽取  0魔  所有存活玩家各失去 1 魔，BOSS 回复实际抽取总量
    - 没有闪避 / 移动 / 休息
    - 索敌：
        魔力×2 < 上限 → 抽取（优先）
        否则魔力≥2 且攻击范围内有玩家 → 鞭挞 / 穿刺 等概率二选一
        否则魔力≥2 且范围内无玩家 → 反击 / 压制 / 爆发 三选一
        否则 → 反击
    - 数值默认：由 关卡7-*boss 文件提供（示例 60 血 / 6 攻 / 6 防 /
      0 体 / 12 魔 / 范围 3）；战斗时只乘难度系数
    - 目标部位：玩家可点击四个部位中的任意一个；未指定时选离攻击者最近的部位；
      选择的部位必须在攻击距离内
    - 穿刺命中防御中的目标时，伤害不减免，但目标仍会防御力 -1 并被击退；
      目标仍可闪避
    - 第 7 层从 关卡7-[金木水火土]boss 随机；BOSS 数值只按难度缩放，
      不乘层数；四格位置与基础数值由关卡文件提供
    - 编辑器已支持 BOSS：模板 5、四格菱形占位、拖动吸附、cells 导入导出

16.12 关卡接入（计划4 第四步）
    - 第 1~6 层：按「种子 + 层号」随机一个元素；层号从
      「当前层 - 1、当前层、当前层 + 1」三种可能中按种子随机，
      排除 0 和 7，读取 关卡{层号}-{元素}.json
      例：当前第 3 层，层号可能为 2/3/4，元素再随机
    - 第 7 层：随机一个元素，读取 关卡7-{元素}boss.json
    - 关卡文件提供：51 格属性、敌人模板 / 主属性 / 位置 / 基础数值；
      BOSS 额外提供 cells 四格
    - 普通敌人数值：
      floor(floor(关卡基础值 × 难度系数) × (1 + (层数 - 1) × 0.1))
    - 第 7 层 BOSS：只乘难度系数，不乘层数；攻击范围取关卡值
    - 关卡加载失败会提示并退回本层选择；格子属性每场按关卡覆盖
    - 旧的 run.enemyTemplates 配置已移除，改由关卡文件驱动

16.13 主角团队（计划5 第六步）
    - 五人角色池「五选三」：主角固定，四名队友选二；只创建选中的三人
    - 全员法术治疗：1 魔，目标为任意存活队友（含自己），回复 1 点体力；
      选择目标后确认，结算时扣魔
    - 主角技能：
        本命一击  3 魔  攻击距离内单体；自身属性克制目标，或自身所在格
                            属性克制目标所在格属性时，造成攻击力×3 伤害；
                            两种克制都不满足时不造成伤害，魔耗照扣
        炼兵  1 魔起  本场攻击力 +1，可叠加；每使用一次，下一次魔耗 +1
        修养  3 魔起  回满血量、体力，防御恢复到战斗前快照；
                            每使用一次，下一次魔耗 +1
        涌动  3 魔起  攻击距离内单体：目标魔力清零，并造成等量伤害；
                            每使用一次，下一次魔耗 +1
        爆炎  2 魔起  攻击距离内单体：造成攻击力×3 伤害（按攻击结算，
                            可被防御 / 闪避）；每使用一次，下一次魔耗翻倍
                            （2→4→8…）
        起甲  0 魔    防御姿态；主角被攻击时触发（每场一次）：本回合免疫
                            所有伤害，并提升 2 点攻击力；战斗结束按快照恢复
    - 队友技能：
        御金  0 魔    沈桐桐防御姿态；本回合具有嘲讽，首次被攻击时护甲 +1
        铸甲  2 魔    全队本场防御力 +1（同时提高本次防御上限）
        生机  2 魔    攻击距离内单体，造成 floor(施法者攻击力/2) 伤害；
                            命中后为主角回复等量生命
        自然  3 魔    任意存活队友（含自己）；目标所在格改为目标主属性，
                            回复 floor(施法者攻击力/2) 生命
        淡修  2 魔    攻击距离内单体，造成攻击力伤害；
                            命中后削减目标 floor(施法者攻击力/2) 魔力
        潮息  3 魔    任意存活队友（含自己），本场攻击力 +2
        灼焰  2 魔    攻击距离内单体，造成攻击力伤害；
                            命中后额外使目标防御力 -1
        爆轰  全魔    攻击距离内单体：消耗全部魔力，
                            造成 floor(魔力×1.5) 伤害
    - 动态魔耗在每场战斗开始时重置；起甲的使用次数也按场重置
    - 起甲只有主角能获得；御金 / 起甲都属于防御姿态，不占用攻击目标
    - 攻击类技能被闪避时，伤害与命中后附效（治疗 / 削魔 / 削防）均不结算；
      技能消耗已扣
    - 求签、宝物、结算等全队效果均作用于当前三人；
      存档 v4 按角色 id 保存三人和队友选择
    - BOSS 战细节、关卡表与模拟结果单独见 `BOSS战.md`
