## 2. 当前背景与相机

背景在 `index.html` 的 `#stage` 内：

- `#bgVideo`：视频背景，静音自动播放、循环。
- `#bgShade`：暗色遮罩。
- `#stage canvas`：Three.js 渲染画布，`z-index: 2`。
- `#stage` 背景为深色兜底。
- `scene.background = null`，渲染器 `alpha: true`，保持透明。

当前资源：

- 视频：`/美术资源/动态背景/video_1792407182426.mp4`
- 海报：`/美术资源/背景图/image_generated_20261019_183935_393_0_f985c28b-6763-42f9-bfe4-d7e5a739186e.jpg`

替换背景视频时：

1. 放入 `美术资源/动态背景/`。
2. 修改 `bgVideo.src`。
3. 同步修改 `bgVideo.poster`。
4. 保持 `muted`、`loop`、`playsinline`，否则浏览器可能阻止自动播放。
5. 保持视频 `pointer-events: none`，不要阻挡棋盘点击。

当前相机：

```js
camera.position.set(0, 9.9, 6.9);
camera.lookAt(0, 0.9, 1.0);
```

棋盘已经下移并降低俯角。美术调整角色高度时，优先通过模型原点/尺寸适配，不要随意改相机，避免 UI 与点击坐标错位。

## 3. 角色模型接入

当前角色由 `buildUnitMesh(u)` 生成，是程序化几何体：

- 单位主体是八面体 `gem`。
- 外圈是阵营色 `ring`。
- 名字/血量是 CanvasTexture `sprite`。
- `group.userData.gem` / `gems` 保存可点击对象。
- `updateHighlights` 默认读取 `u.mesh.children[3]` 作为名字 sprite。

替换 glTF 时保留以下约定：

1. `unit.mesh` 仍是 `THREE.Group`。
2. 点击命中对象继续挂 `unitId`，BOSS 部位继续挂 `partCellId`。
3. 名字/血量 sprite 仍放在第 4 个子节点，或同步修改 `updateHighlights`。
4. 不改变 `layoutUnits` 的同格堆叠高度与缩放。
5. 模型原点建议在脚底中心，朝向统一为面向棋盘中心。
6. 模型尺寸建议：普通单位高度约 `0.7~1.2` 世界单位，BOSS 约 `1.6~2.4`。

同格缩放当前为：

```js
const STACK_SCALES = [1, 0.8, 0.6, 0.4];
```

第 5 个及以后保持 `0.4`。高亮放大倍率 `1.16` 会叠加在堆叠缩放上。

## 4. 3D 资产规格

- 格式：优先 `.glb`；需要独立贴图时用 `.gltf` + textures。
- 坐标：Y 向上，原点在脚底中心。
- 朝向：统一面向 `-Z` 或 `+Z`，在接入层做一次统一旋转。
- 材质：使用可被 Three.js 正确解析的 PBR 材质；避免过多透明层。
- 贴图：2 的幂尺寸优先；颜色贴图标记 sRGB。
- 动画命名建议：`idle`、`move`、`attack`、`hit`、`die`、`cast`。
- 单个角色建议控制在 1~3 万三角面以内；BOSS 可放宽。
- 低端设备降级：降低像素比、关闭粒子和模糊、减少透明材质。

## 5. UI 图标

当前技能面板、藏品卡、地图节点主要使用文字和 CSS。替换图标时：

- 技能按钮：按 `SKILL_TYPES` 分组；图标通过按钮 `::before` 或内联 `img` 接入。
- 地图节点：`NODE_TYPES` 对应打怪 / 奇遇 / 休息 / BOSS。
- 藏品：`ARTIFACTS` 中按 id 对应图标。
- 求签：大吉 / 中吉 / 小吉 / 小凶 / 大凶。
- 图标统一使用正方形 PNG/WebP，透明背景，建议提供 `1x/2x`。

不要因为图标替换改变按钮尺寸和可点击区域。技能列表允许滚动，固定宽度约 300px。

### 5.1 战斗内角色立绘窗口

- 位置：棋盘左侧，`#stage` 内绝对定位，默认隐藏。
- 触发：点击底栏任意角色卡；再次点击同一张卡、点击右上角 `×` 或进入下一场战斗时关闭。
- 内容：上部为立绘与角色名，下部为属性标签和基础属性；基础属性使用内联 SVG 图标。
- 实现：`#unitDossier` + `renderDossier()`；立绘映射在 `PORTRAIT_BY_CHAR`，敌人使用 `image_warrior.jpg`，BOSS 使用 `image_boss.jpg`。
- 属性读取单位当前值（生命 / 攻击 / 防御 / 体力 / 魔力 / 距离），随 `renderUnitBar()` 同步刷新。
- 角色介绍由 `unitIntro()` 按 `charId` / 敌人模板返回，同时显示在底栏角色卡和档案卡下方。
- 替换立绘时保持约 3:4 竖图比例，优先使用透明或半身构图；不要改变窗口对棋盘的点击穿透规则。

### 5.2 选择队友界面

- 四名队友改为单行四列 `pick-grid four`。
- 每张卡上方显示角色立绘，下方按「属性 + 名字」排列，属性用对应五行色标签。
- 选择队友时通过 `modal.classList.add('companion-pick')` 将弹窗扩宽到 900px；`openModal` / `closeModal` 会自动清除该状态，避免影响其他弹窗。

### 5.3 选择名剑界面

- 三把候选名剑改为单行三列 `pick-grid three sword`，每项上方显示名剑图。
- 图片下方依次显示名称、类别和效果说明。
- 名剑图片映射在 `SWORD_IMAGES`，资源位于 `美术资源/名剑/`。
- 只调整选择弹窗；藏品卡（`renderRelicCard`）中的名剑展示逻辑保持不变。

### 5.4 米白主题与开始页

- 顶栏、右侧操作栏、地图、日志、战斗角色卡、弹窗卡片统一改为泛黄米白填充。
- 边框沿用原颜色，主要面板和卡片边框加粗到 1.5~2px。
- 文字改为深褐 / 墨色；属性、阵营标签通过 `color-mix` 加深，保证米白底上的对比度。
- 角色档案窗口宽度放大到 280px，并同步放大标题、属性行和图标。
- 开始页使用 `美术资源/背景图/` 的同一张背景图做模糊铺底；`#startScreen::before` 负责模糊，`::after` 负责暗角，开始卡片位于最上层。
- 名剑选择弹窗宽 600px，队友选择弹窗宽 900px；两者通过 `sword-pick` / `companion-pick` 类控制，不再共用固定宽度。
- 米白主题二次压暗：主面板 `#d8c7a5`、地图 `#dccbaa`、卡片 `#e6d8ba`、弹窗 `#ddcfb0`，通过 `:root` 变量统一维护。
- 窗口分隔线统一为深蓝 `#1f3550`，顶栏、侧栏、地图、技能栏、底栏和弹窗边框加粗到 2~3px。

### 5.5 棋盘格子

- 格子填充改为不透明 `MeshStandardMaterial`，使用同色系偏暗色：金 `#4e3c12`、木 `#1b3d27`、水 `#17345c`、火 `#5a1e16`、土 `#422a1c`；无属性格 `#2a3142`。
- 棋盘底盘 `plate` 保持半透明，`opacity: 0.68`、关闭深度写入，让背景视频能透出。
- 每个格子新增不透明 `RingGeometry` 边框，外径 0.4、内径 0.335，使用同色系偏亮色；无属性格使用亮蓝灰 `#7c8da9`。
- 每个格子新增 128×128 CanvasTexture 标签，居中绘制五行字，字体栈为 `STXingkai / 华文行楷 / 行楷 / KaiTi / 楷体`，使用偏亮同色系，透明度 0.65。
- 无属性格隐藏标签；`refreshCellColors()` 在属性变化时同步刷新填充、边框和文字。
- 高亮缩放同时作用于填充、边框和文字，保持三者在同一格内同步放大。

## 6. 动作与特效接入点

- 主循环：`index.html` 的 `animate()`。
- 单位位置：`layoutUnits()` 更新目标位置，`animate()` 做 lerp。
- 名字/血量：`drawLabel(u, sprite)`。
- 攻击、受击、治疗、护盾等结算在战斗方法中；建议通过事件/状态触发表现，不要把伤害逻辑写进动画代码。
- 棋盘高亮：`updateHighlights()` 控制格子 emissive 与缩放。
- BOSS 四格部位：`group.userData.gems` 与 `partCellId`。

### 6.1 战斗胜利结算动画

- 资源目录：`美术资源/结算动画/`，按角色命名 `video_主角.mp4`、`video_沈桐桐.mp4`、`video_芊儿.mp4`、`video_念乔.mp4`、`video_赤遥.mp4`；BOSS 胜利使用 `美术资源/结算动画/bosswin.mp4`。
- 映射：`SETTLEMENT_VIDEO_BY_CHAR` 与角色 `charId` 对应；`BOSS_WIN_VIDEO` 对应 BOSS 战。
- 触发：回合结束判定胜利后，读取 `lastPlayerDamagerId`，即最后一次造成伤害的我方单位；无记录时回退主角。若当前战斗存在 BOSS 单位，则忽略角色映射，直接播放 `bosswin.mp4`。
- 表现：`#victoryCinematic` 覆盖 `#stage` 棋盘区域；前景 `#victoryVideo` 用 `object-fit: contain` 完整显示视频，背景 `#victoryVideoBackdrop` 用同一视频放大模糊铺满，兼容 16:9 与 3:4 资源；播放结束、加载失败或 12 秒超时后隐藏。
- 流程：胜利后先显示 `#winPrompt`（`美术资源/UI/image_win.png`，z-index 29）约 0.8 秒，再播放动画；提示窗位于棋盘正上方、宽 174px，背景使用主题色，图片以 `multiply` 混合去除白底；提示窗始终压在动画（z-index 28）上方，动画结束后与提示窗一起隐藏，随后才调用 `showSettlement()`。
- 音频：优先带声音播放；浏览器拦截自动播放时自动切静音重试，不阻断结算。

## 7. 地图 UI

当前地图：

- 右侧 `#mapPanel`。
- 7 层纵向画布。
- 层号固定在左侧 `#mapLayerLabels`，不随横向滚动。
- 节点按数量居中：1 个 `0.5`，2 个 `0.33/0.67`，3 个 `0.25/0.5/0.75`。
- 同类节点合并，父节点到具体后继节点画线。
- 当前节点滚动到窗口中间偏上，后继节点在偏下。
- 选择弹窗底部不再显示横向地图。

美术只改节点外观/图标/连线颜色，不要改上面的位置规则和合并逻辑。

## 8. 验收流程

每个美术任务完成后：

```powershell
node 测试脚本/run_tests.mjs
```

涉及数值或关卡时额外跑：

```powershell
node 测试脚本/balance/run_balance.mjs
node 测试脚本/balance/growth_sim.mjs
node 测试脚本/balance/run_campaign.mjs
```

至少检查：

- 页面无 JS/资源 404 错误。
- 视频背景正常播放，棋盘点击正常。
- 5 人选 3 人、布阵、战斗、结算、地图滚动正常。
- 同格多模型缩放按 1.0 / 0.8 / 0.6 / 0.4。
- 低端分辨率下 UI 不溢出。
