五行棋盘 · 玩法设计思路

一、一句话定位
五行相克驱动的五边形战棋肉鸽：用三人小队在 51 格棋盘上打七层路线，靠属性、格子和站位做取舍。

二、设计目标
1. 每回合都有选择：攻击、防御、闪避、改格子、回资源之间要权衡。
2. 每层都有路线选择：打怪、奇遇、休息对应不同的风险和成长。
3. 每局都有成长感：宝剑、藏品、求签、结算奖励共同塑造本局流派。
4. 失败能复盘：输在属性、站位、资源还是路线，玩家能说清楚原因。

三、核心循环
选路线 → 战斗 / 奇遇 / 休息 → 战斗结算成长 → 进入下一层 → 第 7 层 BOSS。
单场战斗循环：布阵 → 每回合决策 → 固定顺序结算 → 胜负判定。

四、战斗设计
1. 双重克制：人物属性克制 + 所在格属性克制，让“站哪儿”和“打谁”同样重要。
2. 克制随层数成长：前期 ±1 易理解，后期逐层放大，避免全程只有一种伤害节奏。
3. 防御不是空过：减伤、削防、击退、反击，让被动选择也有博弈。
4. 闪避消耗体力：强躲避但有资源压力，防止无脑闪避。
5. 决策同时提交：玩家要预判敌人本回合的防御、闪避和嘲讽。
6. BOSS 用部位机制：四个弱点共享血量，鼓励分散攻击和爆发取舍。

五、角色设计
1. 五选三：主角固定，四名队友选二，保证每局队伍组合不同。
2. 主角定调：主属性决定本命法术，玩家先选玩法方向。
3. 队友补位：沈桐桐偏防守/嘲讽，芊儿偏治疗，念乔偏削魔，赤遥偏爆发。
4. 技能分工：基础技能保证下限，专属技能提供流派差异。

六、肉鸽成长
1. 难度与幸运：高难度敌人更强，但幸运影响路线、求签和结算强化。
2. 宝剑开局：给本局一个明确起点，例如幸运、攻击、上限或回复。
3. 奇遇与藏品：三选一，用有限藏品位做构筑取舍。
4. 休息与结算：生命上限和单体攻击成长，提供稳定的长期收益。
5. 求签：每场战斗开场的小型随机事件，增加单场变数但不改写大局。

七、节奏安排
第 1~2 层：熟悉克制、防御和站位。
第 3~4 层：开始形成队伍分工和藏品组合。
第 5~6 层：数值压力上升，路线和资源管理变得关键。
第 7 层：BOSS 检验队伍输出、生存和部位处理能力。

八、表现与体验
1. 棋盘用五行色和格子文字强化属性识别。
2. 角色卡、档案卡、立绘和结算动画负责角色记忆点。
3. UI 统一米白主题和深蓝分隔，保证长时间阅读不疲劳。
4. 规则书分“1 分钟上手”和“完整规则”，降低首次进入成本。

九、后续方向
1. 增加敌人组合和关卡机制，避免每层只靠数值变化。
2. 扩充藏品与事件，让更多流派可行。
3. 接入角色模型、动作和技能特效，提升战斗反馈。
4. 持续用模拟和真人对局校验 BOSS 难度与路线收益。
5. 保持规则可读：新机制优先做成“看得懂的一个选择”，而不是叠加数值。
